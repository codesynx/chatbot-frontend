Our Technology

Our platform uses Convolutional Neural Networks (CNNs) to analyze fundus images and identify various eye conditions:

  • Diabetic Retinopathy
  • Glaucoma
  • Age-related Macular Degeneration (AMD)
  • Cataracts
  • Hypertension-related Eye Conditions
  • Pathological Myopia

We utilize the Ocular Disease Intelligent Recognition (ODIR-5K) dataset, which contains 5,000 patient records, ensuring our model is trained on diverse, real-world data. By applying advanced transfer learning techniques with architectures like VGG19 and ResNet50, we achieve over 90% classification accuracy.

Our Data Security

We recognize the critical importance of safeguarding user information. To maintain the highest standards of data protection, we implement the following measures:

  • Secure Data Storage

    Patient information is stored using encrypted databases to ensure data confidentiality.

  • Access Control

    We enforce strict access control mechanisms to limit data availability to authorized users only.

  • Data Anonymization

    Personally identifiable information is anonymized during processing to protect user privacy.

  • Continuous Monitoring

    Our system undergoes continuous security monitoring to detect and respond to potential threats in real time.

  • User Authentication System

    Includes user registration, login, OTP verification, and secure password recovery through email-based verification.
